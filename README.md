# Portfólio de Data Analytics & Data Science

Este repositório reúne projetos desenvolvidos durante minha formação em Data Science pela FIAP, além de estudos e projetos práticos voltados à resolução de problemas de negócio por meio de dados.

Os projetos apresentados aqui demonstram a aplicação prática de SQL, Python, Power BI, Databricks, Excel, modelagem de dados, ETL e análise exploratória, abrangendo desde o tratamento e transformação dos dados até a construção de indicadores, dashboards e análises para apoio à tomada de decisão.

## Projetos

| Projeto | Foco | Tecnologias |
|---|---|---|
| [Cidade Alfa — MDM de Cidadãos (PBL Fase 6)](fase_6_mdm_oracle/README.md) | Integração de fontes, qualidade de dados e consolidação cadastral | Oracle SQL, PL/SQL, VS Code e Git |

A Fase 6 apresenta a consolidação de 100 cidadãos, o registro de divergências entre fontes e uma view analítica por faixa etária e escolaridade.
